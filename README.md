# Predictive Modeling Archive

Earlier predictive modeling work spanning regression, classification, feature engineering, and model evaluation. The flagship wildfire-risk and bankruptcy-risk projects now live in standalone repositories.

## Archived Projects

- [Salary Survey Data Cleaning and Modeling](salary-survey-data-modeling/README.md): My first machine learning project began with crowdsourced salary surveys shared by TikTok users. I combined files through SSIS and SQL Server, then used pandas to standardize job titles, industries, countries, and currencies. The cleaned data supported salary analysis and exploratory prediction models. The central challenge was turning inconsistent survey responses into a dataset suitable for analysis.
- [Cleaning Marketplace Shoe Data for Price Modeling](shoe_price_prediction/README.md): Compare regression approaches for estimating product prices from marketplace data; the Ridge model reported the lowest mean absolute error among the evaluated models.
- [Climate Trends Across Hemispheres](Climate_Analysis/README.md): Compare historical temperature anomalies across the Northern and Southern Hemispheres. Linear trend analysis finds statistically significant warming in both, with greater variability and more extreme anomalies in the Northern Hemisphere.
- [MLB Performance and Pitching Analytics](baseball_stats/README.md): Transform MLB data from 2018–2024 into interactive views of run expectancy, actual versus expected batting averages, and pitching performance. The project combines Python-based data retrieval and cleaning with Tableau dashboards and a companion visualization website.
- [Clinical Significance of Genetic Mutations](clinical_disease/README.md): Analyze ClinVar-derived records to identify 19,474 harmful mutations and connect common mutation values with associated genes and diseases. Three Tableau dashboards make the mutation patterns and clinical significance easier to explore.
- [FIFA 20 Player Analysis](soccer_analysis/README.md): Pair the FIFA 20 player dataset with an analysis notebook to compare player attributes and ratings across positions, clubs, and countries.
- [Twitter Engagement and Sentiment Analysis](tweets_analysis/README.md): Analyze posting activity, sentiment, and hashtag engagement to identify actionable timing patterns. The findings highlight weekday activity peaks around 11 a.m.–3 p.m. and stronger engagement for hashtags including `dataviz`, `d3js`, and `BigData`.
